# Dia 04 - Letra Mais Frequente

## Objetivo

Criar um programa que analisa um texto e identifica qual letra aparece com maior frequência.

## Conceitos praticados

- Ciclos `for` aninhados.
- Contadores temporários.
- Comparação de valores.
- Armazenamento do maior valor encontrado.
- Manipulação de strings.
- Conversão de texto com `lower()`.

## Aprendizado principal

Aprender a resolver problemas onde é necessário:

1. Analisar cada elemento individualmente.
2. Contar ocorrências.
3. Comparar resultados.
4. Guardar o melhor resultado encontrado até ao momento.

## Observação

A solução inicial utiliza dois ciclos `for`, realizando várias verificações sobre o texto.

No futuro, este algoritmo poderá ser otimizado utilizando estruturas de dados mais adequadas, reduzindo o número de percursos necessários.
