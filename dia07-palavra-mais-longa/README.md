# Dia 07 - Palavra mais longa

## Objetivo

Criar um programa que analisa uma frase e identifica a palavra com maior quantidade de letras.

A solução deve mostrar a palavra encontrada e o respetivo número de caracteres.

Exemplo:

- Frase: `O Gustavo estuda programação`
- Resultado: `A maior palavra é: programação com 11 letras`

## Conceitos praticados

- Criação de funções.
- Percurso de strings com ciclos `for`.
- Construção de palavras caractere por caractere.
- Concatenação de strings.
- Contagem de caracteres com `len()`.
- Métodos de strings:
  - `isalpha()`
- Comparação de comprimentos.
- Armazenamento da maior palavra encontrada.
- Formatação de resultados com `f-string`.

## Aprendizado principal

Praticar a divisão de um texto em palavras sem utilizar métodos prontos, analisando cada caractere e separando as palavras quando encontra um espaço ou outro caractere que não seja uma letra.
