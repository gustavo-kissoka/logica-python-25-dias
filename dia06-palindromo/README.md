# Dia 06 - Palíndromo

## Objetivo

Criar um programa que verifica se uma palavra ou frase é um palíndromo, ou seja, se é igual quando lida da esquerda para a direita e da direita para a esquerda.

O programa deve ignorar espaços e diferenças entre letras maiúsculas e minúsculas.

Exemplos:

- `arara`
- `A base do teto desaba`

## Conceitos praticados

- Criação de funções.
- Percorrer strings com ciclos `for`.
- Concatenação de strings.
- Manipulação de texto.
- Métodos de strings:
  - `isalpha()`
  - `lower()`
- Comparação de strings.
- Retorno de valores booleanos com `True` e `False`.

## Aprendizado principal

Praticar a limpeza e a comparação de textos, aprendendo a construir uma versão normalizada e a percorrer os caracteres em sentido inverso antes de verificar se são iguais.

## Observação

A solução inicial utiliza ciclos `for` para remover os caracteres que não são letras e para construir o texto invertido.

No futuro, o algoritmo poderá ser simplificado utilizando operações de string mais diretas.
