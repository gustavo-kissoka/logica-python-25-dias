# Dia 03 - Analisador de Texto

## Objetivo
Criar um programa que analisa um texto e contabiliza diferentes tipos de caracteres:

- Vogais
- Consoantes
- Números
- Espaços
- Outros caracteres

## Conceitos praticados

- Criação de funções.
- Ciclo `for` para percorrer strings.
- Operador `in`.
- Métodos de strings:
  - `isalpha()`
  - `isdigit()`
  - `isspace()`
- Estruturas condicionais (`if`).
- Contadores.

## Aprendizado principal

Praticar a classificação de caracteres, analisando cada elemento individualmente e separando-os em diferentes categorias.

## Observação

A solução inicial utiliza várias funções independentes para facilitar a compreensão da lógica. Futuramente será possível otimizar o código realizando a análise em uma única passagem pelo texto.
