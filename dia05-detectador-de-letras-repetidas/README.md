# Dia 05 - caracter que duplicados

Este programa mostra lé palavras ou frases e diz quais são os caracteres que mais estão duplicados.

# conceito praticado

- Ciclos `for` aninhados.
- Contadores temporários.
- Comparação.
- Armazenamento do maior valor encontrado, mesma abordagem do dia04
- Manipulação de strings.
- operador `in`

## Observação

A solução inicial utiliza dois ciclos `for` usando a mesma abordagem do dia04. 

No futuro, este algoritmo poderá ser otimizado.
