# 🧠 Desafio de Lógica Python - 25 Dias

## Sobre o projeto

Este repositório representa a minha evolução no desenvolvimento de raciocínio lógico e programação utilizando Python.

O objetivo principal não é apenas aprender sintaxe da linguagem, mas desenvolver a capacidade de resolver problemas, criar algoritmos, melhorar a organização do código e pensar como um programador.

---

## Objetivos

Durante os 25 desafios, o foco será desenvolver:

- Raciocínio lógico
- Pensamento computacional
- Resolução de problemas
- Organização de código
- Boas práticas de programação
- Eficiência e melhoria de soluções

---

## Metodologia

Cada desafio possui:

- Um problema proposto
- Uma tentativa de resolução
- Análise da solução
- Melhorias de lógica e eficiência

A ideia é evoluir gradualmente, começando por problemas simples e aumentando a dificuldade conforme novos conceitos são aprendidos.

---

## Conteúdos praticados

Ao longo do desafio serão explorados conceitos como:

- Variáveis
- Condições (`if`, `elif`, `else`)
- Ciclos (`for`, `while`)
- Strings
- Listas
- Dicionários
- Funções
- Manipulação de dados
- Algoritmos de pesquisa
- Organização de pequenos sistemas
