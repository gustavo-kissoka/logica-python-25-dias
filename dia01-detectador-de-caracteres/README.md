# Dia 01 - Detector de Caracteres

## Objetivo
Criar um programa que analisa uma entrada do utilizador e identifica a quantidade de:

- Letras
- Números
- Espaços
- Outros caracteres

## Conceitos praticados

- Entrada de dados com `input()`
- Estruturas condicionais (`if`, `elif`, `else`)
- Ciclo `for`
- Percorrer strings
- Contadores
- Métodos de strings:
  - `isalpha()`
  - `isdigit()`
  - `isspace()`

## Aprendizado principal

Praticar a lógica de percorrer uma informação caractere por caractere e classificar cada elemento encontrado.
