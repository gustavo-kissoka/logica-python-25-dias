# Dia 08 - Anagrama

## Objetivo

Criar um programa que verifica se duas palavras ou frases são anagramas.

Um anagrama ocorre quando as letras de um texto podem ser reorganizadas para formar o outro texto. O programa deve ignorar letras maiúsculas, espaços e caracteres que não sejam letras.

Exemplos:

- `Listen` e `Silent`
- `Dormitory!` e `Dirty room`

## Conceitos praticados

- Criação de funções.
- Percurso de strings com ciclos `for`.
- Manipulação e normalização de texto.
- Métodos de strings:
  - `isalpha()`
  - `lower()`
- Comparação de comprimentos com `len()`.
- Utilização de listas.
- Ciclos `for` aninhados.
- Retorno de valores booleanos com `True` e `False`.
- Substituição de caracteres já utilizados durante a comparação.

## Aprendizado principal

Praticar a comparação entre dois textos sem considerar caracteres irrelevantes. Foi aprendido a limpar o texto, verificar primeiro se os comprimentos são iguais e, em seguida, confirmar se todas as letras do primeiro texto existem no segundo.
