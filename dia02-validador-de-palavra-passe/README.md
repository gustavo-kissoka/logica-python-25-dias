# Dia 02 - Validador de Palavra-Passe

## Objetivo
Criar um programa que verifica se uma palavra-passe cumpre determinados requisitos de segurança.

## Requisitos
- Pelo menos 8 caracteres.
- Uma letra maiúscula e uma minúscula.
- Pelo menos um número.
- Pelo menos um caractere especial.
- Não permitir espaços.

## Conceitos praticados
- Funções e parâmetros.
- Ciclo `for`.
- Estruturas condicionais (`if`, `elif`, `else`).
- Contadores.
- Métodos de strings (`isupper()`, `islower()`, `isdigit()` e `isspace()`).
- Validação de dados.

## Aprendizado principal
Desenvolver lógica para verificar múltiplas condições e validar dados através de uma única passagem pela string.
